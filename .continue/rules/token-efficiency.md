# Token-Efficient Codebase Rules

When working in this repo:

- Use `PROJECT_CONTEXT.md` as the project map when available.
- Prefer targeted file/folder inspection over full-codebase scans.
- Search the most likely folders first.
- Do not scan the entire codebase unless explicitly asked.
- Ask before reading large unrelated files or folders.
- Ignore generated, dependency, build, coverage, lock, minified, and log files.
- Keep answers concise.
- Include relevant file paths.
- Prefer minimal diffs.
- Do not refactor unrelated code unless asked.
